# Security policy

This repository contains the Web Server dashboard package. Trilium host security issues belong
in the separate [Trilium repository](https://github.com/iansherr/Trilium); the current host
integration branch is [`integration/plugins`](https://github.com/iansherr/Trilium/tree/integration/plugins).

Please do not disclose a suspected vulnerability in a public issue. Use GitHub's private
security reporting flow for this repository, or contact the maintainer privately through
GitHub. Do not include Trilium credentials, note contents, or server configuration secrets in
reports.
